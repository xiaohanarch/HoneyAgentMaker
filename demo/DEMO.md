# 演示讲解词

本文件是 15 分钟演示的操作脚本。每个故事一张表，列出分钟段、界面操作（点哪里）、可以照读的讲解词、观众看到什么，以及这一步参照的 Joule 能力与设计主题。两个映射列只标到主题，完整的对应关系见 `docs/joule-mapping.md`。演示者先读「演示前准备」；演示身份一览见附录一，演示控制台按钮与端点的对应见附录二。

六个故事相互独立，每个都从自己的确定起点开始：讲完一个故事，用演示控制台跳到下一个故事的起点，再切到该故事的主角身份。这样任何一屏出错都能就地恢复，也可以单独演示其中任何一个。

## 演示前准备

启动与访问：

- `pnpm install && pnpm demo` 一条命令拉起全部服务，不需要任何大模型 API Key。就绪后浏览器打开 http://localhost:5173。
- 演示默认使用脚本化模型（剧本在 `demo/scripts/`），断网可用，回复内容与数据完全可预期。设置 `EAB_MODEL_PROVIDER` 与对应的 Key 环境变量可以切到真实模型，界面操作路径不变，回复文字由模型生成；关键机制（工具调用、约束触发、确认点、拒绝路径）不受影响。现场网络不稳时建议保持脚本化模型。
- 屏幕分辨率 1440 宽效果最好，1280 宽可用（投屏场景）。支持深色模式，演示建议浅色。

演示控制台：

- 顶部右上角的滑杆图标是演示控制台。重置数据、跳到各故事起点、触发业务事件、模拟标品升级、切换演示身份都在这里。
- 演示状态操作（重置、故事起点、一键完成态、模拟升级）只对租户管理员开放，所以每个故事开始前先切到赵管理员，跳完起点再切到主角。
- 重置会清空运行、追踪、通知、扩展需求，并撤回演示中发布的租户资产（扩展、技能、评测集、语义包）；连接、工具来源、工作流、远程 Agent 与标品资产保留。故事 A 到 E 的起点都是纯重置；故事 F 的起点在重置后发布完成态快照，让升级回归有对象。
- 「一键完成态」不进主线：它发布快照并生成 30 天模拟历史，供治理中心看趋势，观众提问时可以顺手展示。

时间预算：只有 10 分钟时，讲开场加故事 A、B、D、F，故事 C 与 E 各留一句口头介绍；每个故事的行可以按观众背景取舍，故事 D 的反查和故事 F 的架构视图建议保留。

## 开场（1 分钟）

以张敏身份站在统一入口页讲：

> 这是一个面向多租户 ERP 的 Agent 开发平台。ERP 厂商的研发团队在它上面开发随产品交付的标品 Agent；租户在标品之上做扩展，也可以从一句话意图新建自己的 Agent；用其他框架写的 Agent 经 A2A 接进来，平台里的 Agent 也能被外部调用。最终用户只面对一个统一入口。

> 接下来的十五分钟讲七件事。第一，它是一个开发态工具，有完整的设计、测试、发布、运行、观测生命周期。第二，平台分三层资产：平台层、厂商标品层、租户层，租户看不到也改不了标品的核心。第三，租户可以增强标品 Agent：追加指令、加工具和技能、挂钩子和人工确认点，标品升级时自动回归。第四，租户可以从一句话意图新建 Agent，AI 全程给推荐。第五，外部框架的 Agent 通过 A2A 接入，与原生 Agent 共用一个入口，反过来平台里的 Agent 也能被外部调用。第六，Agent 不越权：用户在 ERP 里做不了的事，通过 Agent 也做不了，写操作分级、人工确认、全程审计。第七，业务用户发现能力缺口可以直接提需求，开发者用 AI 生成扩展并上线，形成闭环。

## 附录二：演示控制台与端点对应

演示控制台的每个按钮对应一个平台端点，全部走同源的 `/api` 代理，也可以用 curl 直接调用（需要 Bearer 用户令牌）。

| 按钮 | 端点 | 说明 |
| --- | --- | --- |
| 重置演示数据 | `POST /api/demo/v1/reset` | 语义与 `pnpm seed:reset` 一致：先重置 DemoERP，再重置平台 |
| 故事 A–E 起点 | `POST /api/demo/v1/story-start`，体 `{"story":"A"}` | 纯重置，并重建演示委托 |
| 故事 F 起点 | `POST /api/demo/v1/story-start`，体 `{"story":"F"}` | 重置后发布 `tenants/t001` 完成态快照 |
| 一键完成态 | `POST /api/demo/v1/complete` | 快照加 30 天模拟历史，治理中心可看趋势 |
| 交付逾期 / 库存低于安全线 / 交易异常 / 结账检查失败 | `POST /api/demo/v1/events`，体 `{"type":"delivery.overdue"}` 等 | 推送业务事件，匹配的 Agent 以受托方式运行，结果进委托人通知区 |
| 模拟发布 1.3.0 并跑租户扩展回归 | `POST /api/hub/demo/upgrade` | 已是 1.3.0 时会报错，先跳故事 F 起点 |
| 对照（集成账号对照） | `GET /api/hub/demo/integration-compare?user=<登录名>` | BO API 与 Open API 的同一问题对照 |

门禁与限流：

- 演示模式未开启（非 demoMode）时，演示端点一律返回 404。
- 演示状态操作（reset、story-start、complete）只对租户管理员开放，其他身份 403；触发业务事件对租户内任意身份开放。
- 演示状态操作每用户每分钟 10 次，超限返回 429。

演示控制台的其余能力不点按钮也有等价入口：委托撤销在治理中心「委托管理」，集成账号对照在治理中心「审计」页，历史数据用 `pnpm data:simulate` 生成。
