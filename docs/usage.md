# 使用指南

这份指南面向想自己动手把演示环境跑起来、把六个故事都走一遍的读者，覆盖启动、身份选择、每个故事的操作路径、页面功能、真实模型切换和常见问题。给观众做演示时的完整讲解词在 `demo/DEMO.md`，两份文档配合使用：`DEMO.md` 给讲的人，这份给动手的人。系统结构见 `docs/architecture.md`。

## 启动

环境要求：Node.js 22 或更新版本、pnpm 9、JDK 21。Maven 由仓库内的 Maven Wrapper 自动下载。外部 Python 样例需要 uv，不装也不影响主流程。

```bash
pnpm install
pnpm demo
```

默认使用脚本化模型，不需要任何大模型 API Key，断网也能运行。启动脚本会等全部服务健康检查通过后打印访问地址，浏览器打开 http://localhost:5173。停止服务在运行 `pnpm demo` 的终端按 Ctrl+C。

首次运行端到端测试前执行一次 `pnpm exec playwright install chromium`。服务与端口一览见 `README.md`；也可以用 Docker（`docker compose up --build`，独立安装的旧版 Compose 用 `docker-compose`）。

## 走一遍六个故事

六个故事相互独立，都从自己的确定起点开始。套路相同：先用赵管理员在演示控制台跳该故事的起点，再切到主角身份操作。任何一步出错，回到控制台重新跳一次起点即可恢复。

故事 A，从一句话新建 Agent。跳「故事 A · 新建助手」，切到陈工进 Studio，首页「从一句话意图新建 Agent」输入「帮采购经理制定和供应商的降价谈判策略」，沿十三步向导逐步采纳模型推荐，在评测集一步生成用例并运行，切到「测试」以张敏的身份试跑（链路里能看到约束触发），发布到 dev 并依次晋级 test、prod，最后切到张敏在统一入口直接使用。

故事 B，增强标品 Agent。跳「故事 B · 增强标品」，切到陈工，Studio「扩展标品 Agent」打开交易异常解析 Agent，新建扩展：追加指令、加 IM 通知工具、挂结果钩子、设确认点，每页保存后在「有效定义」页看标品指令的占位块与租户片段，评测通过后发布；切到王芳提问，扩展生效，写操作前弹出确认卡。

故事 C，外部互通。跳「故事 C · 外部互通」，切到陈工，Studio「接入外部 Agent」读取 Agent Card、做连通测试、发布；切到张敏问「百润精密最近有没有什么风险」，路由选中外部的供应商风险舆情 Agent，追踪里有 A2A 请求与响应原文。反向调用在终端跑 `pnpm --filter @eab/client-demo run start`，先看无身份被拒绝，再到治理中心审计页看入站记录。

故事 D，Agent 不越权。跳「故事 D · 权限治理」，切到张敏问「列出我们逾期超过 30 天的供应商」，路由澄清时点选供应商绩效分析，结果按华东过滤；切到李强问同一句话，只有华南。控制台「集成账号对照」看 Open API 不按用户过滤的对照。张敏改交期（L2 确认后提交变更单），再让 Agent 审批自己提交的变更单，被职责分离拒绝；治理中心撤销库存 Agent 的委托后触发库存事件被拒绝；审计页反查 PO-2026-0117 定位运行。

故事 E，需求闭环。跳「故事 E · 需求闭环」，切到张敏问备选供应商补货，拿到能力缺口卡，补充说明后提交扩展需求；切到陈工在「待处理的开发需求」里生成方案、采纳草稿，到「我的草稿」运行评测并发布，回需求页标记已交付；张敏在通知区点「重新提问」，确认后拿到请购单草稿。

故事 F，升级治理。跳「故事 F · 升级治理」（点两次确认），再点「模拟发布 1.3.0 并跑租户扩展回归」，到治理中心「升级回归」页看扩展钩子用例失败的报告；切到王芳提问，结果卡点「结论有误」提交反馈，赵管理员在「经验回流」页审核通过写入语义包，王芳重新提问看结论变化；最后赵管理员进架构视图，选王芳刚才的运行，单步或播放回放。

每一步的讲解词、观众看到什么、对应能力，见 `demo/DEMO.md` 的故事表格。

## 演示控制台

顶部右上角的滑杆图标打开。功能：

- 重置演示数据：清空运行、追踪、通知、扩展需求，撤回演示中发布的租户资产；连接、工具来源、工作流、远程 Agent 与标品资产保留。
- 故事起点：故事 A 到 E 是纯重置，故事 F 在重置后发布完成态快照，让升级回归有对象。
- 一键完成态：发布快照并生成 30 天模拟历史，供治理中心看趋势，不在演示主线里。
- 业务事件触发：交付逾期、库存低于安全线、交易异常、结账检查失败，匹配的 Agent 以受托方式运行，结果进委托人通知区。
- 模拟发布 1.3.0：用租户扩展的评测集跑升级回归；已是 1.3.0 时会报错，先跳故事 F 起点。
- 集成账号对照：同一问题走 BO API 与 Open API 的返回对照。
- 切换演示身份。

演示状态操作（重置、故事起点、一键完成态、模拟升级）只对租户管理员开放，其他身份返回 403；每用户每分钟 10 次，超限返回 429。控制台按钮对应的端点清单见 `demo/DEMO.md` 附录二。

## 页面导览

统一入口（首页）：提问后可以看到路由面板（两级路由的候选、分数、理由）、结果卡、确认卡（L2 写操作先确认再执行）、澄清卡（路由置信度不足时请用户在候选里选）、追踪（模型、工具、约束、鉴权的 span 树）和通知区。

IM 渠道：左侧是 Agent 推送到本租户 IM 群的消息，右侧以 IM 方式向助手提问。

Studio：从一句话意图新建 Agent（十三步向导）、扩展标品 Agent、接入外部 Agent、我的草稿与最近编辑、工具中心、技能、连接中心、待处理的开发需求。

治理中心：运行列表、审计（含按业务对象反查）、委托管理、升级回归、经验回流、指标趋势。

架构视图：选择一次运行，按时间线单步或整体播放回放，组件随 span 依次点亮。

## 切换到真实模型

模型配置只从环境变量读取，界面操作路径不变：

```bash
EAB_MODEL_PROVIDER=anthropic ANTHROPIC_API_KEY=... pnpm demo
```

OpenAI 兼容协议用 `EAB_MODEL_PROVIDER=openai`、`OPENAI_API_KEY` 加 `EAB_OPENAI_BASE_URL`。档位映射 `EAB_MODEL_FAST`、`EAB_MODEL_REASONING`、`EAB_MODEL_JUDGE`，单次输出上限 `EAB_MODEL_MAX_TOKENS`，超时与重试 `EAB_MODEL_TIMEOUT_SECONDS`、`EAB_MODEL_MAX_RETRIES`。以 systemd 部署时可以把这些变量放在仓库外的配置文件里用 `EnvironmentFile` 加载（部署单元已预留），本地运行直接在 shell 里设置即可。

真实模型下回复文字由模型生成；工具调用、约束触发、确认点、拒绝路径不受影响。模拟升级的回归要跑评测集，真实模型下单次约十分钟。

## 命令行与脚本

| 命令 | 作用 |
| --- | --- |
| `pnpm agent:run <Agent> --user <用户> "<话术>"` | 进程内跑一次 Agent，打印流式事件与追踪树，断网可用 |
| `pnpm eval:smoke` | 进程内运行评测集，冒烟档 3 分钟内跑完；可加 `--tier full` |
| `node scripts/acceptance-p2.mjs` … `acceptance-p10.mjs`、`acceptance-procode.mjs` | 对运行中的演示环境做各阶段验收（只用 HTTP） |
| `node scripts/demo-walkthrough.mjs` | 按 `demo/DEMO.md` 主线走查机制，起点自带重置 |
| `pnpm eab <子命令>` | 专业代码通道 CLI，详见 `docs/pro-code.md` |
| `pnpm tools:import-bo --write` | 从 DemoERP 的 OpenAPI 同步 BO 工具的入参 schema |
| `pnpm --filter @eab/client-demo run start` | 模拟外部平台经 A2A 调用平台的采购助手 |
| `pnpm data:simulate` | 生成 30 天演示历史，治理中心用它展示趋势 |

## 数据的保存与重置

数据都在仓库根目录的 `data/` 目录（SQLite）。`pnpm seed:reset` 把演示数据重置到初始状态，语义与控制台的重置一致；`pnpm data:backup` 做数据快照到 `data/backups/`，保留最近 10 份。

## 远程部署与访问

部署说明见 `docs/deployment.md`。部署在远程主机上时，本地运行 `scripts/ecs.sh tunnel` 建立 SSH 隧道，浏览器打开 http://localhost:5173 就能像本地一样使用。

## 常见问题

端口被占用。六个端口（4000、4100、5173、4200、4210、4400）被残留进程占用时启动会失败，常见原因是上一次没有正常停止。Windows 上用 `Get-NetTCPConnection -LocalPort <端口>` 找到进程再结束。

某个故事走不下去了。用演示控制台跳该故事的起点，或者直接重置演示数据。重置会清掉运行记录与已发布的租户资产，标品资产不受影响。

控制台按钮点不动或报错。演示状态操作只对租户管理员开放（其他身份 403），每分钟限 10 次（429）；模拟升级在标品已是 1.3.0 时会报错，先跳故事 F 起点。

想断网演示。保持默认的脚本化模型即可，全部功能可离线运行；真实模型需要网络。

端到端测试起不来。首次运行前执行 `pnpm exec playwright install chromium`；测试会自动拉起演示环境，与其他正在运行的环境共用端口，先停掉再跑。
